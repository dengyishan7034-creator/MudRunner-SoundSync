# 验证范围

- 从本包 9 个 C 源文件成功编译生产 DLL 与测试 DLL；没有原主 DLL 输入。
- 67 项车辆、数据校验、网络转发、会话/序列、左右声道、熄火/离车/超时静音、缓存上限和 Windows 音频输出检查通过。
- 72 组 DEFLATE 检查、9 组截断输入检查及输出边界、ZIP/目录覆盖、CRC 损坏拒绝等检查通过。
- 本机游戏 36 种已有车型的运行时声源解析结果与此前核对过的定义全部一致。
- 系统 DirectInput8Create 转发检查返回成功并创建接口。
- 已移除图形设备挂接路线，不再需要 Direct3D9 设备创建检查；改用只读原生渲染器视图矩阵并增加相应指针/矩阵校验。
- 0.4.2 已完成实际启动、进入地图、UAZ/引擎/位置、原生摄像机和 Steam 接口验证。
- 0.4.2 双人吉普联机收发和游戏声音加载成功，用户确认对方引擎声、左右方向及熄火均正常。

更多实测结果记录在 verification.json。不同版本、纯 Epic/EOS、全部第三方车型、多玩家长期运行和精确 RPM 均未全面验收。仓库不包含私人原始日志或游戏文件。
